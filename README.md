# MBA — HR Analytics
### University of Kashmir | MBA Programme

---

## About This Course

This repository contains all lecture notes, datasets, and exercises for the **HR Analytics** course. The course teaches students to use data and analytical methods to understand workforce issues and support better people decisions.

**Teaching Philosophy:** Business problem → HR data → Analysis → Insight → Decision

## How to Use This Repository

### Students
1. Go to the file you need
2. Click **Download raw file** (top right)
3. Save a copy with your name: `KashmirTech_Dataset_YourName.xlsx`
4. Complete the exercises
5. Submit through the course portal

### Lecture Notes (Printing)
1. Download the `.html` file
2. Open in **Chrome or Edge**
3. Press `Ctrl+P` → Set margins to **Minimum** → Save as PDF

## Course Dataset — KashmirTech Solutions

A fictional technology company with **500 employees** used throughout the entire semester.

| Variable | Description |
|----------|-------------|
| Employee_ID | Unique identifier |
| Age | Employee age in years |
| Gender | Male / Female |
| Department | Sales, IT, HR, Finance, Operations |
| Job_Level | Junior, Mid, Senior, Manager |
| Salary | Annual salary (INR) |
| Years_at_Company | Tenure in years |
| Performance_Rating | 1–5 scale |
| Training_Hours | Hours of training received |
| Job_Satisfaction | 1–5 scale |
| Overtime | Yes / No |
| Manager_Rating | 1–5 scale |
| Promoted_Last_2_Years | Yes / No |
| Attrition | Yes / No |
